Copia de seguridad

Guarda o restaura toda tu configuración y tu registro de archivos en un archivo encriptado.

Crear copia de seguridad
Incluye tu configuración (Client ID de OAuth, URL del blog, API key de TMDB, blog e idioma) y el registro de Mis archivos. Descarga un archivo .thb encriptado para guardarlo o pasarlo a otro dispositivo.
Guarda este código en un lugar seguro.
Restaurar copia de seguridad
Restaura desde un archivo .thb descargado antes, o pega un código de texto. Tu registro de archivos se fusiona con el actual (no se borra nada).
Copia de las entradas del blog
Exporta todas las entradas de tu blog (películas, series y animes con sus datos y servidores) a un archivo .thbposts. Después puedes volver a publicarlas en un blog con tu sesión iniciada.
Para importar necesitas iniciar sesión y seleccionar un blog (en «Mi cuenta»). Las entradas se vuelven a publicar una por una.
